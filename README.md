**Weather Forecast App**
A simple and responsive Weather Forecast App that provides real-time weather information and forecasts for locations around the world.

**Features**
    - Current weather conditions
    - Temperature, humidity, wind speed, and pressure details
    - Multi-day weather forecast
    - Search weather by city name
    - Responsive and user-friendly interface
    - Error handling for invalid locations

**Technologies Used**
    - Frontend: HTML, CSS, JavaScript
    - Weather Data API
    - Responsive UI components

**Getting Started**
**Prerequisites**
    - Modern web browser
    - Internet connection
    - API key (if required by the weather service provider)

**Installation**
- Clone the repository:
  ```bash
  git clone <repository-url>
  ```
- Navigate to the project folder:
  ```bash
  cd weather-forecast-app
  ```
- Configure your weather API key in the application settings.
- Run the application locally.

**Usage**
1. Enter a city name in the search box.
2. Click Search.
3. View current weather conditions and forecast information.
